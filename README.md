# TAIL

> 一个还在继续生长的交易工作台。

TAIL 是我们正在做的一套交易控制平台。最开始只是想把市场观察、策略和运行状态放在一个地方，后来一路补上风险、恢复、核对和证据，慢慢变成了现在这个样子。

这次先把项目放出来。它还不是可以直接拿去跑真钱的成品，也暂时没有安装包；这里先讲清楚我们已经做到了哪一步、还在解决什么，以及以后准备把它带到哪里。

TAIL 当前以 Solana 作为第一个参考市场。长期目标不是再做一个只适配单一市场的交易机器人，而是保留同一套策略、风险、状态和证据体系，通过独立 Adapter 接入不同的交易环境。

<sub>TAIL is a customizable workspace for market research, strategy operations, risk control and evidence-driven execution.</sub>

## 它不只是一个桌面界面

TAIL 的后台已经覆盖从市场事件进入系统，到策略、风险、订单意图、恢复和核对的一整条链路：

```text
市场事件
→ 解析与统一
→ 信号与策略
→ 风险检查
→ 订单意图
→ 执行准备
→ 状态核对
→ 持仓与退出
→ 恢复与 Evidence
```

真正花时间的往往不是“发出一笔订单”，而是断线以后怎么恢复、重复事件会不会执行两次、重启后还能不能接上之前的状态，以及本地记录和市场事实不一致时究竟相信谁。

这些东西在截图里不太显眼，但它们决定了一个交易系统能不能继续往下做。更完整的拆分见 [能力清单](CAPABILITIES.md)。

## 接下来想做什么

方向很明确：一个控制层，多种策略，多个市场。

- **跟单关系**：把信号来源、账户约束、风险预算、订单意图和结果核对放进同一条可追踪链路；
- **自主策略**：策略先经过研究、回放、模拟和受控验证，再讨论真实资金；
- **多市场 Adapter**：当前先把 Solana 做扎实，后续再评估数字资产交易平台、A 股和其他金融市场；
- **持续运行的 Runtime**：桌面端负责查看和控制，真正的长期任务由独立服务承担；
- **容量验证**：数千级跟单关系是目标，只有完成可复现的基准测试后才会写成现有能力。

路线不是承诺日期，而是验证顺序。详情见 [路线图](ROADMAP.md) 和 [规模与市场边界](SCALE-AND-MARKETS.md)。

## 该认真说明的边界

当前公开预览不包含钱包、私钥、Token 或生产凭据，也不开放生产执行代码。

代码存在、历史测试通过和界面上出现一个按钮，都不等于已经获得真实资金权限。目前不能把 TAIL 描述为已经完成自动实盘、自动卖出、自动清仓或数千级容量验证，也不提供任何收益承诺。

这部分不会用轻松文案带过，详细说明见 [安全边界](SECURITY-BOUNDARY.md) 与 [公开范围](PUBLIC-SCOPE.md)。

## 这次公开到什么程度

`0.0.1` 是一次早期预热：先公开产品方向、架构、当前状态和开发记录。这次已经补上第一批界面截图，演示视频也通过 GitHub Release 单独发布，避免把二进制视频永久塞进仓库历史。安装包、脱敏演示数据与可运行 Showcase 后续继续补。

目前还没有确定开源许可证。仓库公开可见不代表默认允许复制、修改或再分发，最终许可会在白名单代码导出前单独确定。

如果你也在研究交易系统、恢复与核对、多账户执行，或者只是对这个桌面工作台感兴趣，欢迎先关注项目、提出具体场景或问题。我们更希望收到真实问题，而不是钱包、账户和凭据信息。
